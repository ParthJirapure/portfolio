Cloud & Mobile

EmpFlow: Cloud-Based HR Information System

Project-Based Learning (PBL) • Cloud Project • IEEE Format Paper

Problem Solved

Traditional human resource workflows suffer from fragmented employee record-keeping, slow manual search, paper-based credential verification, and clumsy report generation. EmpFlow solves this by centralizing employee records in one cloud platform to streamline day-to-day HR administrative operations.

Key Features & Engineering Decisions

  • Role-Based Authentication: Secure login with tiered permissions separating HR administrators from general staff.
  • Live Employee Search: Instant indexed search across departments, employee IDs, and roles powered by Cloud Firestore.
  • QR Code Employee ID: Automatic generation and scanning of unique cryptographic QR codes for rapid employee identification.
  • Automated Export Engine: On-demand export of filtered employee rosters and department analytics into formatted PDF and Excel documents.
  • Real-time Cloud Messaging: Firebase Cloud Messaging (FCM) integration for instant company-wide alerts and policy notifications.

Personal Contribution & Documentation

Architected Flutter UI components, Firestore schema rules, and Firebase Storage integration for digital document records. Co-authored the formal academic project paper prepared in IEEE publication format.

Technologies Used

Flutter Dart Cloud Firestore Firebase Storage Cloud Messaging PDF / Excel Export

AI / Machine Learning

AQI Prediction Using Machine Learning

Environmental AI & Applied Supervised Learning • Python

Problem Solved

Urban air pollution metrics (PM2.5, PM10, NO2, CO, SO2) exhibit complex non-linear dynamics, making standard statistical averages unreliable for timely health advisories. This project builds a multi-model comparative machine learning benchmark to forecast local Air Quality Index (AQI) readings with maximum precision.

Key Features & Engineering Decisions

  • Comparative Model Benchmarking: Trained and benchmarked Random Forest, XGBoost, and K-Nearest Neighbors (KNN) algorithms on real-world pollution records.
  • Data Preprocessing Pipeline: Imputed sparse pollutant measurements, engineered diurnal cycle features, and standardized continuous numerical variables.
  • IoT Telemetry Exploration: Designed input integration protocols for physical IoT air sensors to stream real-time local air samples into the inference pipeline.
  • Performance Evaluation: Evaluated models using Root Mean Squared Error (RMSE), Mean Absolute Error (MAE), and R-squared coefficient metrics.

Personal Contribution & Key Findings

Identified that ensemble tree-based models (XGBoost and Random Forest) significantly outperformed KNN due to their capability to capture sudden seasonal shifts and meteorological anomalies.

Technologies Used

Python Scikit-learn XGBoost Random Forest Pandas & NumPy IoT Sensors
